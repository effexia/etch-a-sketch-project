# etch-a-sketch-project

A browser-based Etch-a-Sketch drawing application built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Dynamic grid generation with a customizable grid size.
- Adjustable grid dimensions without changing the overall drawing area.
- Random RGB colors when hovering over individual squares.
- Progressive darkening effect: each interaction increases the square's opacity by 10%, reaching full color after ten interactions.
- Clear and regenerate the grid with a new size.

## Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM Manipulation and Event Handling)

## What I Learned

- Creating and manipulating DOM elements with JavaScript.
- Handling mouse events.
- Working with CSS Flexbox to create a responsive grid.
- Using JavaScript to dynamically modify CSS properties.
- Working with random number generation and RGB colors.
- Managing user input and validating values.
